# Науковий Барометр / Scientists Barometer

Сайт-дашборд інтерсуб'єктивних **індексів якості наукової діяльності в Україні** —
за аналогією з Індексом споживчих настроїв / PMI, але для стану науки.

Дані формуються самими науковцями (опитування). Перша хвиля — пілотне дослідження N=200 (2026).
Агреговані дані хвилі опубліковано на Zenodo: https://doi.org/10.5281/zenodo.23161485

## Стек

- **Astro** (статична генерація, zero-JS за замовчуванням) + Tailwind
- Графіки — HTML/CSS на етапі збірки (`IndexForest`, `DistBar`, `Meter`, теплокарти розрізів)
- Хостинг: Cloudflare Pages (`public/_headers` — сувора CSP: лише `script-src 'self'`)

## Розробка

```sh
npm install
npm run dev      # локальний сервер
npm run build    # статична збірка → dist/ + перевірка scripts/check-dist.mjs
```

`check-dist.mjs` падає, якщо в зібраному сайті з'явилась згадка внутрішнього звіту або інлайн-скрипт
(CSP його заблокувала б).

## Дані

`src/data/*.json` — агрегати, які копіює `sync_site_data.py` з репозиторію аналізу (він приватний;
сюди потрапляють **лише агрегати**, ніколи мікродані):

- `wave-2026.json` — метадані хвилі, 24 індекси з 95 % ДІ, не-індексні показники, надійність,
  репрезентативність;
- `block-*-2026.json` — шість блоків анкети: розподіли, розрізи за групами, дослівні коментарі;
- `verification-2026.json` — розподіли відповідей за індексами, статистики шкал, пари конструктів,
  відомі групи й перевірки узгодженості (те, з чого числа перераховуються);
- `crosstab-ci-2026.json` — 95 % ДІ для кожної клітинки розрізів (до версії 1.0 набору на Zenodo
  не входять).

> Етика: дані публікуються **лише безособово й агреговано**. Сирі відповіді респондентів у репозиторій
> не потрапляють; групи з n < 5 у розрізах придушено.
